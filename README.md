# Filament v4 - Playground

Hands-on exploration of Filament v4 - the latest major version of the
most popular Laravel admin panel framework.

Filament v4 introduced significant changes to the component architecture
and UI system. This repo covers practical testing of the new features
before adopting them in production projects.

## Topics covered
- Installation and initial setup
- Resource CRUD with new v4 UI components
- Form and table builder changes vs v3
- Panel customization

## Stack
PHP - Laravel - Filament v4 - Livewire - Blade

## Context
I follow the Filament ecosystem since v3. Keeping up with major version
changes is part of staying current with the Laravel stack.
